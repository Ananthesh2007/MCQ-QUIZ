# MCQ Quiz

A study-focused web application for practicing multiple-choice questions across engineering subjects. The project provides a clean dashboard to choose a subject, select a unit, and take quizzes in either PDF-order or random mode.

## Overview

This project is a static HTML/CSS/JavaScript quiz portal designed for students preparing for engineering courses. It includes:

- Subject-wise quiz navigation
- Unit-wise question selection
- Two quiz modes:
  - PDF Order
  - Random Mode
- Timer and score tracking
- Progress indicator
- Result summary after completion

## Features

- Subject dashboard for various engineering topics
- Unit-based question grouping
- Multiple-choice question interface
- Answer submission and validation
- Instant feedback on each question
- Final score summary and restart flow
- Responsive layout for desktop and mobile screens

## Tech Stack

- HTML5
- CSS3
- JavaScript

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/Ananthesh2007/MCQ-QUIZ.git
```

2. Open the project folder:

```bash
cd MCQ-QUIZ
```

3. Open `index.html` in your browser.

You can also use a local web server if preferred:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
